# agent-settings

Личная коллекция настроек для автономных AI-агентов: операционные правила (инструкции) и кастомные навыки (skills). Репозиторий приватный — содержит персональные рабочие настройки и не предназначен для публичного использования.

## Состав репозитория

```
agent-settings/
├── instructions/
│   └── PIPELINE.INSTRUCTIONS.md   # Правила работы агента и справочник по инструментам
└── skills/
    └── disk-space-audit/          # Кастомный навык: аудит места на диске (Windows)
        ├── SKILL.md               # Описание и рабочий процесс навыка
        ├── evals/
        │   └── evals.json         # Тестовые сценарии (evals) навыка
        ├── references/
        │   └── junk-patterns.md   # Шпаргалка по «мусорным» папкам Windows
        └── scripts/
            └── measure.ps1        # Скрипт измерения размера папок/файлов
```

## Инструкции

[`instructions/PIPELINE.INSTRUCTIONS.md`](instructions/PIPELINE.INSTRUCTIONS.md) — единый свод правил для агента:

- **Базовые ограничения:** проверка первоисточников, точечные правки (`edit` вместо `write`), соблюдение стиля и линтеров, отказ от «разговорных» концовок.
- **Расширенное мышление и память:** когда использовать `sequentialthinking` и граф памяти (`memory_*`).
- **Платформозависимые инструменты:** `background_process`, Context7/`websearch`, Agent Manager, браузерная автоматизация, локальный поиск контекста, визуализации (`chart` vs Mermaid).
- **Индекс навыков:** триггеры для `plan`, `research`, `frontend-design`, `cross-review`/`zen-review`, `cavecrew`, `grill-me`, `agent-browser`.
- **Петля самопроверки:** сверка перед завершением задачи.

## Навыки (skills)

### disk-space-audit

Кастомный навык для **только чтения** аудита места на диске Windows. Агент сканирует диск, находит крупные папки/файлы и мусор от удалённых программ и формирует сгруппированный отчёт (`удалить / не точно / перенести / системные`). Ничего не удаляет и не меняет без явной просьбы пользователя — команды очистки выдаются только как рекомендации.

Структура навыка:

| Файл | Назначение |
|------|-----------|
| `SKILL.md` | Триггеры, жёсткие правила (read-only), рабочий процесс, шаблон отчёта |
| `scripts/measure.ps1` | Детерминированное измерение размера подпапок/файлов (`-Top`, `-Files`) |
| `references/junk-patterns.md` | Категоризация находок: `DEL` / `ASK` / `MOVE` / `SYS` |
| `evals/evals.json` | Сценарии проверки поведения навыка |

Пример вызова измерительного скрипта:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "skills/disk-space-audit/scripts/measure.ps1" -Path "C:\Users\racfo" -Top 25
```

## Установка

1. Склонировать приватный репозиторий:

   ```powershell
   git clone <url-приватного-репозитория> agent-settings
   ```

2. Подключить содержимое к используемому агенту:
   - Скопировать `instructions/PIPELINE.INSTRUCTIONS.md` в директорию конфигурации агента (например, как `AGENTS.md` или в раздел инструкций).
   - Скопировать папку `skills/disk-space-audit/` в каталог навыков агента (например, `C:\Users\<user>\skills\disk-space-audit`).

> Конкретные пути подключения зависят от используемого агента/расширения.

## Приватность

Репозиторий **приватный**. Не содержит секретов в явном виде, но включает персональные пути профиля (`C:\Users\racfo\...`) и специфичные для окружения настройки. При публикации в публичный доступ предварительно обезличьте пути профиля и имена пользователя.
